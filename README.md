# Word Guess Game

A command-line word-guessing game built in Python where players guess letters to reveal a hidden word within a limited number of wrong attempts, with score tracking and a persistent leaderboard.

## Features

- Guess letters to reveal a hidden word
- Tracks wrong guesses (max 6 per round)
- Score awarded based on number of wrong guesses
- Leaderboard saved to a JSON file, persists across sessions
- Simple menu: play, view top scores, or exit

## Technologies Used

- Python 3
- Built-in modules: `random`, `json`, `os`
